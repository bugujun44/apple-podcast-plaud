# apple-podcast-plaud

Bridge: a downloaded Apple Podcasts episode → Plaud upload + transcription
→ structured Markdown + JSON envelope you can hand to any agent flow.

## When this skill applies

- User has already downloaded an Apple Podcasts episode on the **same Mac**
  Claude Code is running on (the m4a sits in Apple's local cache; this
  skill reads its SQLite to find it).
- User wants the **text** of the episode — typically Chinese podcasts
  where Apple does not generate native transcripts.
- User has a paid Plaud subscription and has run `apb auth set-token`
  / `apb auth login` once already (verify with `apb auth status`).

## When this skill does NOT apply

- Episode hasn't been downloaded yet → tell the user to open Apple
  Podcasts and tap the cloud icon to download first; then re-trigger.
- User wants to transcribe an arbitrary audio file not in Apple Podcasts
  → use a different tool (Plaud's web app upload, Whisper, etc.).
- Plaud auth not configured → tell the user to run
  `apb auth set-token` (or `apb auth login`); see the package README.

## Tool: `apb` CLI

The skill is a thin wrapper around the `apb` command from the
`apple-podcast-plaud` Python package. It must be on PATH (typically by
sourcing the project's `.venv/bin/activate` or installing globally).

```
apb list-podcasts -n N             # list recent downloads (table)
apb list-podcasts -n N --json      # same, JSON
apb transcribe "<keyword>"         # locate, upload, wait, write artifacts
apb auth status                    # confirm token still valid
```

`apb transcribe` writes:

- `~/Documents/podcasts/<YYYY-MM-DD>-<sanitized-title>/transcript.md`
- `…/summary.md` (Plaud's AI summary)
- `…/transcript.raw.json`
- `…/metadata.json`

…and prints a JSON envelope to stdout:

```json
{
  "status": "ok",
  "podcast": "...", "episode": "...", "language": "zh",
  "duration_sec": 1815, "segment_count": 48,
  "out_dir": "/Users/.../podcasts/2026-04-27-...",
  "files": {
    "transcript_md": "...", "summary_md": "...",
    "raw_json": "...", "metadata_json": "..."
  },
  "source": "plaud", "plaud_recording_id": "...",
  "elapsed_sec": 187
}
```

## Workflow

1. **Disambiguate the episode**. If the user named it specifically
   ("天才女友 第三季"), use that as the keyword. If they said something
   vague ("最近那期"), run `apb list-podcasts -n 5` first and let them
   pick.

2. **Run the transcription**:
   ```bash
   apb transcribe "<keyword>" --json-out -
   ```
   Plaud transcription takes 2–5 minutes for a 30-min episode;
   `apb` blocks until done. Stream stderr to the user as a progress
   indicator if you can.

3. **Read the JSON envelope** off stdout. Parse it. Read
   `files.transcript_md` if downstream actions need the verbatim
   text; `files.summary_md` if the user just wants the gist.

4. **Decide what to do with the transcript** based on the *original*
   user request:
   - "Just transcribe" → tell them where the file is. Done.
   - "Write me a 公众号文章 from this" → read the transcript,
     hand it to whatever writing flow is appropriate.
   - "Add to my knowledge base" → move/copy the out_dir to the
     user's KB ingestion folder.
   - Etc. The skill itself never decides; the calling agent does.

## Common errors and fixes

| Error | Likely cause | Fix |
|---|---|---|
| `No downloaded Apple Podcasts episode matches '...'` | Not yet downloaded, or keyword too narrow | Run `apb list-podcasts -n 20` and ask user to pick |
| `401 from Plaud. Token expired` | Token rotated server-side or > 10 months old | `apb auth set-token` with a fresh token |
| `AnalysisTimeoutError` | Plaud queue is slow; recording > 1h | `apb transcribe ... --timeout 1800` (default 1200s) |
| `Plaud rejected the password` | Account is Google-sign-in only | Use `apb auth set-token` (Path B) instead of `auth login` |

## Red lines

- **Never accept tokens or passwords pasted into chat.** If the user
  pastes one, immediately tell them to rotate it on web.plaud.ai (logout
  → re-login → `copy(localStorage.getItem('tokenstr'))` in DevTools
  Console → `apb auth set-token` in their terminal). Do not write any
  pasted credential to disk.
- **Never invent a podcast or episode.** If `apb list-podcasts` shows
  no match for the requested keyword, say so. Do not pretend to find
  something to make the user happy.
- The transcript is generated by Plaud's ASR; treat it as best-effort.
  Common Chinese homophone errors (e.g. 逆商→逆伤) require manual
  correction; flag this when surfacing the transcript.
